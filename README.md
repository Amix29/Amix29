<p>I joined GitHub in 2023, but I've been really active since early 2026. I started using AI back when ChatGPT was released in January 2022.</p>

<p>At first, I was just experimenting a bit by posting videos on TikTok 📱. Then I saw a YouTube video 🎥 that showed ChatGPT could code a working calculator. I thought it was incredible that AI could code things.</p>

<p>Then the years went by, and I kept experimenting with different AIs and tools: ChatGPT, Claude, Bolt, Lovable, etc. 🧪</p>

<p>Then DeepSeek and Qwen came along. The more Chinese models were released, the more I became interested in open source 🌐, and I think it’s incredible that the Chinese manage to innovate with every new release.</p>

<p>On May 31, 2026, I released Multi-Converter, my very first project 🚀. That’s when the entire open-source AI ecosystem really started to interest me.</p>

<p>I don’t know how to code, but I think that today, it’s still very important to have the basics and a certain developer’s mindset 💻.</p>

<p>In my opinion, the future of AI isn’t about subscriptions or the cloud—it’s about on-premises AI 🖥️, which almost anyone will be able to run simply by using open-source projects and connecting them to open-source apps.</p>

<p>I also think that AI models shouldn’t be proprietary, but open source 🔓, to prevent a single entity from controlling a field as important as AI.</p>
